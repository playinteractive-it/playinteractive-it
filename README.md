## Featured project

**[PI Motion](https://github.com/playinteractive-it/pi-motion)** is a small JavaScript library that turns HTML attributes into scroll-driven animations, built on GSAP, ScrollTrigger and SplitText. Instead of writing code for each animation, you describe the effect in the markup.
